# PRD — 오늘의 구절 앱 디자인 개편 (Directed Version)
> 디자인팀에게 방향성이 명시된 버전. 논의된 결정을 그대로 전달한다.

---

## 1. 제품 개요

**앱 이름**: 오늘의 구절  
**플랫폼**: iOS / Android (Flutter)  
**한 줄 설명**: 매일 아침 성경 구절 하나를 조용히 마주하는 앱

---

## 2. 타겟 사용자

**20-40대 신앙 유지형 기독교인** — 매일 QT를 챙기고 싶지만 성경을 길게 읽을 여유는 없는 직장인·육아 세대. "짧고 깊게"에 반응하는 사람들.

---

## 3. 감성 방향

| 항목 | 방향 |
|------|------|
| 핵심 감성 | 고요함 + 따뜻함 |
| 시각 언어 | Editorial + Organic |
| 참고 앱 | Hallow, Day One, Bear |
| 피해야 할 것 | 경건하고 무거운 종교적 장엄함, 일반 유틸리티 앱 느낌 |

> "아침에 커피 한 잔처럼 자연스럽게 열 수 있는 앱"

---

## 4. 화면 구성 (4개)

```
[메인 페이지]
      ↓ 아이콘 탭
[구절 경험]          [히스토리]     [설정]
  책설명 ↔ 구절
```

---

## 5. 화면별 상세 요구사항

---

### 5-1. 메인 페이지 (Landing / Threshold)

**개념**: 일상과 성경 구절 사이의 전이 공간. 사용자가 마음의 준비를 하고 "입장"하는 곳. 고전 RPG 타이틀 화면의 감성.

**레이아웃**:
- 중앙: 브랜드 일러스트 이미지
- 하단: 아이콘 3개 (텍스트 없음) — [구절] [히스토리] [설정]

**일러스트**:
- 스타일: 흑백 스티플링(stippling) — 점의 밀도로 명암을 표현하는 점묘 기법. 고전 성경 삽화 또는 판화 느낌.
- 소재: 교회 또는 성당 외관
- Phase 1 (현재): 고정 이미지
- Phase 2 (추후): 날짜별로 바뀌는 일러스트로 업그레이드

**내비게이션 버튼**:
- 아이콘만, 텍스트 레이블 없음
- 아이콘 3개: 구절 진입 / 히스토리 / 설정

---

### 5-2. 구절 경험 (Verse Experience)

**개념**: 앱의 핵심. 책 배경(맥락)을 먼저 만나고, 구절을 읽는 2단 경험.

**구조**: 수평 PageView (좌우 스와이프)
```
[Page 1: 책 설명]  ←→  [Page 2: 구절]
```

**Page 1 — 책 설명**
- 오늘 구절이 속한 성경 책의 배경 설명 (3-4문장)
- 앱 진입 시 자동 TTS 재생 (책 설명 낭독)
- 스크롤 가능 (긴 텍스트 대응)
- 스와이프하면 TTS 중단 → Page 2로 이동

**Page 2 — 구절**
- 오늘의 구절 2절을 하나의 페이지에 함께 표시 (기존 PageView 방식 폐기)
- 구절 진입 시 TTS 자동 재생 (구절 낭독)
- 스크롤 가능

**공통**
- 상단 좌측: 앱 심볼 아이콘 → 탭하면 메인 페이지로 복귀
- 상단 우측: TTS 재생/정지 아이콘

**진입 트랜지션**:
- 메인에서 구절 경험 진입 시: 페이드인 (~600ms)
- 부드럽되 느리지 않게

---

### 5-3. 히스토리 (History)

**개념**: 지난 날의 구절을 다시 찾아보는 아카이브

**구조**:
- 날짜별 카드 리스트 (최신순)
- 카드: 날짜 + 책명 + 참조 (예: `로마서 8:28-29`) + 구절 첫 줄 preview
- 탭 → 해당 날의 구절 경험으로 그대로 진입 (책설명 ↔ 구절 동일 구조)

---

### 5-4. 설정 (Settings)

**현재 설정 항목 유지**:
- TTS ON/OFF 토글
- TTS 볼륨 슬라이더
- 테마 선택 (라이트 / 다크 / 시스템)
- 개발자 후원 링크

**디자인 방향**: 앱 전체 감성(세피아 + Editorial)과 통일감을 유지. 일반 Flutter 설정 화면 느낌 탈피.

---

## 6. 디자인 시스템

### 6-1. 색상

| 역할 | 라이트 | 다크 |
|------|--------|------|
| 배경 | 세피아 크림 (`#F0E8D8` 계열) | 따뜻한 다크 (`#1C1A16` 계열) |
| 카드/서피스 | 배경보다 약간 진한 세피아 | 배경보다 약간 밝은 다크 |
| 포인트 | 골드 (`#8B6914` 계열) | 골드 (`#D4A843` 계열) |
| 텍스트 High | 짙은 세피아 브라운 | 따뜻한 오프화이트 |
| 텍스트 Mid | 중간 회갈색 | 중간 회색 |
| 텍스트 Low | 연한 회갈색 | 연한 회색 |

> 핵심 원칙: 차갑지 않은 색. 모든 중립색은 따뜻한 계열(노랑/갈색 편향)로.

### 6-2. 타이포그래피

| 역할 | 폰트 | 용도 |
|------|------|------|
| 구절 본문 | 나눔명조 (serif) | 구절 텍스트 |
| 책 설명 / UI 본문 | Noto Sans KR | 설명 텍스트, 설정 등 |
| 날짜 / 참조 / 영문 숫자 | Cormorant Garamond 또는 EB Garamond | 날짜, `로마서 8:28` 등 영문+숫자 요소 |

> 나눔명조 + Cormorant Garamond 조합이 "고전 성경 삽화책" 분위기를 완성한다.

### 6-3. 일러스트 스타일 가이드

- **기법**: 스티플링 (Stippling) — 점의 밀도와 간격으로 명암 표현
- **색상**: 흑백 (컬러 없음)
- **소재**: 교회/성당 외관. 창문의 빛, 돌의 질감이 잘 표현될수록 좋음
- **참고 키워드**: "stippling church illustration", "pen and ink cathedral", "biblical engraving style"
- **배경 위 배치**: 세피아 배경 위에 올렸을 때 자연스러운 대비 확인 필요

---

## 7. 핵심 UX 원칙

1. **입장의 의식** — 메인 페이지는 구절로 들어가기 전 잠깐 멈추는 공간. 강제 진입 없음.
2. **맥락 먼저, 말씀 나중** — 책 설명(TTS)을 먼저 듣고 구절을 읽는 흐름.
3. **소리와 텍스트의 분리** — TTS는 각 페이지 진입 시 자동 재생. 스와이프로 스킵.
4. **군더더기 없는 화면** — 버튼 레이블 없는 아이콘, 텍스트 최소화. 콘텐츠가 주인공.
5. **스크롤 대응** — 모든 콘텐츠 페이지는 스크롤 가능.

---

## 8. 기술 제약 (디자인팀 참고용)

- Flutter 기반 크로스플랫폼 (iOS/Android)
- 다크모드 / 라이트모드 / 시스템 자동 모드 3종 지원 필수
- TTS: 책 설명용 + 구절용 2개 오디오 파일 (WAV)
- Firestore에서 오늘 날짜 문서를 실시간으로 읽어옴 → 로딩 상태 디자인 필요
- 구절 데이터: 책명 + 장 + 절 + 절텍스트(2절) + 책설명 + 오디오URL
